# VALHÄUS

.NET 8 e-commerce platform with Stripe payments and Google OAuth.

## Setup

**Windows:**
```powershell
.\setup-windows.ps1
```

**Linux:**
```bash
chmod +x setup-linux.sh
sudo ./setup-linux.sh
```

## Running the App

**Windows:**
```powershell
dotnet run --project VALHÄUS\VALHAUS.csproj
```

**Linux:**
```bash
dotnet run --project VALHÄUS/VALHAUS.csproj
```

Open http://localhost:8080
